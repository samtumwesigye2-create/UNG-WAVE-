# LINK256 5G Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make 5G NR the preferred autonomous WAN for UGANET LINK256, with LTE fallback and Ethernet/Wi-Fi backup selection.

**Architecture:** Add a focused ModemManager-backed cellular module and a WAN selector that ranks healthy links. Keep the UGANET AP independent from WAN availability so local service never disappears when cellular drops. Expose status/control through the existing FastAPI service and preserve subscription gating on the selected egress.

**Tech Stack:** Python 3, FastAPI, ModemManager/mmcli, NetworkManager/nmcli, iptables, pytest.

**Spec:** Approved in chat on 2026-09-10.

## Global Constraints

- 5G NR is preferred; LTE/4G is automatic fallback.
- UGANET Wi-Fi must remain available when WAN disappears.
- SIM PINs, APNs, carrier credentials, and secrets must not be committed to the public repository.
- Ethernet and external Wi-Fi remain lower-priority fallback WANs.
- Existing subscription entitlement enforcement remains authoritative.
